# Ottoman Palestine Immigration Research

## Purpose

This repository is designed to support an academic-quality research project on immigration, refugee settlement, and population growth in Ottoman Palestine, roughly 1830-1914.

The central research question:

**What role did immigration and refugee settlement play in the population growth of Ottoman Palestine between 1830 and 1914?**

## Core Principle

Separate four categories at all times:

1. Directly documented migration events
2. Settlement evidence
3. Population counts
4. Demographic residual estimates

Do not treat inferred migration as documented migration.

## Repository Structure

- `sources/` stores source documents and scans.
- `data/raw/` stores unmodified downloaded or uploaded data files.
- `data/extracted/` stores hand-extracted tables from sources.
- `data/processed/` stores cleaned datasets.
- `database/` stores the SQLite database and schema.
- `papers/` stores paper drafts.
- `notes/` stores working notes and research logs.
- `status/` stores running status files.
- `scripts/` stores import/export scripts.
- `exports/` stores generated CSVs, charts, maps, and submission files.

## Current Status

## Key Warning

The hypothesis that large numbers of Muslim refugees entered Palestine is testable, but not yet proven. The database is structured to prevent the evidence from being forced into a predetermined conclusion.
