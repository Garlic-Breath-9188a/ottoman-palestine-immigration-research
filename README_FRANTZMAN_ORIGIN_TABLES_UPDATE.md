## Main Finding

Frantzman's own tables identify explicit external-origin categories:
- Algerians
- Egyptians
- Circassians
- Bosnians
- Lebanese
- possible Transjordanian links
- Bedouin mobility categories

This does not prove mass immigration, but it weakens any broad claim that external migration was insignificant or analytically irrelevant.
